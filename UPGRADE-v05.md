# Four Corners v0.5 — Animated Footballer Upgrade

Changes: Procedurally rigged articulated footballers (arm/leg gait), visible heads/faces, kits, socks, shoes, back numbers, and selected character jersey/gender reflected in the 3D arena. No external 3D model dependencies.

This is an intermediate **stylized, low-poly human** upgrade, not a photorealistic scanned/motion-captured footballer. Accurate real-time animation, facial modelling, Blender GLB assets, professional football motion capture, and full multiplayer game physics remain future work.

Run: npm install; npm run dev; then Play > Training.
