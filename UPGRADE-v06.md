# Four Corners v0.6 — Stylized player polish + visible stone goals

- Each goal is TWO independent stone blocks roughly 0.96 world units apart (approximately 3 ft / 0.91 m between marker centers). No net or crossbar.
- Goal ownership labels and distinct painted ground markers: North/Red, East/Blue, South/Your Goal, West/Gold.
- Camera widened and raised slightly to help view distant goals; player tracking remains adaptive.
- Added stylized kit accents and a more visible patterned ball.
- Existing local practice and multiplayer-room prototype are retained.

These changes do not add rigged professional character assets or network-authoritative ball physics.

To run: npm install; npm run dev. Use Play > Training.
